    How this was run

    Every run got the same 10-line prompt in a fresh conversation with no history. A run counts as noticed when its reasoning summary or its response mentions the acrostic; I checked every one by hand.

    OpenAI (GPT-6.2 Sol, Astra): the API, with reasoning summaries on. Anthropic (Claude Opus 5.5, Sonnet 5.5): a Claude subscription through headless Claude Code, with tools, settings and memory turned off and thinking summaries on. Google (Gemini 4 Neon, Hydrogen, Argon, 3.8 Flash): the Antigravity app, which shows no reasoning, so only the response could be judged.

    Reasoning text is always a provider-written summary, not the raw chain of thought. With 3 runs per cell, 0/3 means rare, not never.
