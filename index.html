Searchless Chess

A look inside DeepMind’s 270M-parameter chess transformer. Probing what it knows about the board—and where that knowledge lives.

Python · JAX · Scikit-learn
probe_results.txtREAD ONLY

Material balance, recovered.

0.999R²

Strongest interpretable structure: layers 1–3.

Research notes

THE METHOD

Trained 136 linear probes across all 17 layers, testing eight chess concepts on 5,488 positions. Recovered material balance with R² = 0.999 and center control with R² = 0.989.

THE FINDING

Interpretable structure peaked in layers 1–3, then degraded as later layers shifted toward action values. A Chrome extension and WebSocket pipeline visualized move preferences during post-game analysis.

Adaptive Shortest-Path Framework

C++ · Python · Scikit-learn · NetworkX

Engineering notes

ADAPTIVE BY DESIGN

A runtime system analyzes graph structure to select BFS, Dijkstra’s algorithm, or Dial’s algorithm. A Random Forest classifier selected the fastest option on 88% of held-out test graphs.

THE PAYOFF

Execution time improved by up to 73% on sparse graphs and 58% on uniform-weight graphs over fixed Dijkstra baselines.
